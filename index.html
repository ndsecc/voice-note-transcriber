Voice Note Transcriber for WhatsApp Web

A Chrome extension by NextdoorSEC

Turns WhatsApp Web voice messages into text automatically, right under each voice message, so you and the AI agents you use can read them. Audio goes only to the speech-to-text provider you choose, with your own API key. Transcripts stay in your browser.
